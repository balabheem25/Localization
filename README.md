This project is a code proposal for localization of sensor which is placed in a enclosed space, currently focussing on 2D space in ideal REST condition for minimizing
the complexity of the project. Many assumptions were made to create a dataset having similar input parameters. Most of the parameters are general in application of
Ultrasound as signal source. Many approaches were tried even with the Neural Networks and Particle Filter. For current version, LocalizedFinalCode.py is the last updated
code with reasonable Accuracy and MSE. ANd the current developing version is gobanana-algo.py to define the particle filter in the best case possible for no movement in 
sensor position by introducing noise to Particle Filter which can resemble the use case (hopefully).

The application which this project has the scope of localizing a sensor in human body for Energy Transmission and Data Transmission using UltraSound)
